# 棱镜假日 · Prism Days

一款浏览器桌游：选择地图，与具名电脑代理人独自旅行，或用 6 位房间码与好友联机。包含四季天气、地产、道具、股票、随机事件和结算榜。

## 运行

推荐 Node.js 24 LTS（最低 22.12），版本提示见 `.nvmrc`。首次运行：

macOS 可以直接双击 [启动棱镜假日.command](启动棱镜假日.command)。脚本会在首次运行时安装依赖、缺少构建产物时构建，然后启动本地服务；在浏览器打开 `http://localhost:8787/`。保持弹出的终端窗口打开，关闭窗口会停止服务。如果 8787 端口已有服务，脚本会提示并保留现有进程。

也可以在终端手动运行：

```bash
npm ci
npm run dev
```

开发页面默认由 Vite 提供；WebSocket 房间服务运行在 8787 端口，Vite 将 `/ws` 代理给它。其他同一局域网设备可通过本机 IP 与开发页面端口访问。生产构建与启动：

```bash
npm run build
npm start
```

生产服务在 8787 端口同时提供 `dist` 页面和 `/ws`。公网联机需要自行把服务部署到可访问的主机，并提供安全的 HTTPS/WSS 入口；本地运行本身不会开放公网。

支持 `PORT` 和 `HOST` 环境变量；默认分别为 `8787` 和 `0.0.0.0`。生产服务器应使用单个常驻进程，部署在独立域名的根路径。健康检查为 `/healthz`。容器构建、HTTPS 反向代理、发布检查及回滚步骤见 [生产部署说明](docs/DEPLOYMENT.md)。

## 对局

PVE 在浏览器中运行并自动保存到本机，也可在游戏设置中导出与导入 JSON 存档。随机种子可在高级规则中设置，用于重现同一局初始条件。PVP 的对局状态由房间服务维护，刷新后会使用本机身份和房间码重连。离开房间时不会有电脑替真人行动。房主可以补充具名电脑代理人；所有真人就绪后方可开局。房产自由交易默认开启，房主可在开局前关闭；开启时产权人可挂牌，其他玩家购买后立即完成现金与产权交割。

四季各 21 天。旅程长度通过四档滑条选择 1、2、4 年或破产决胜。信标形状可直接点选灰色图标；天气通过胶囊按钮选择标准／挑战／苦难，新对局默认挑战。租金负担通过胶囊选择轻松／标准／沉重，默认为标准，普通地产分别采用初版的 3／5／10 倍租金，基建不变；房主可在开局前统一设置。房间等待页支持修改自己的名字。正常行进每满72格获得10000棱镜币，始初森林缩短为24格，伟岸之城为48格；免租卡可在付款前手动选择，控骰器可指定普通骰的1～6点，天气修正仍生效。

标准天气提供「温和天气体验」，挑战提供「完全体天气体验」，苦难则是「直面大自然的怒火」：强化非晴好天气，重点增加心情压力，提高极端与灾难概率，并逐图适配气候。苦难从第 1 天起允许灾难；标准与挑战仍从第 22 天起开放。完整效果与地图概率见 [苦难天气设计](docs/HARDSHIP_WEATHER.md)。

AI 可选择温和或凌厉，两档都包含谨慎、平衡、激进三种流派。凌厉会主动采购、经营与择机进攻；温和不主动攻击，事件选择也会权衡收益。详见 [代理人设计](docs/AI_OPPONENTS.md)。

始初森林搭配沉重负担时，每位玩家初始资金翻倍为 200000 PM；伟岸之城所有档位每人以 150000 PM 开局，其他组合仍为 100000 PM。破产模式搭配轻松负担会显示不推荐警告，提示可能长期循环、难以结束，仍可继续开局。组合说明同步显示在大厅和好友房间，已有存档余额保持不变。

寂静河谷可建到五层，第五层才成为受保护地标。伟岸之城有 50 栋未售预制楼（一、二层各 15 栋，三、四层各 10 栋），按地价加已有楼层建造成本整栋认购，保留楼层；另有 8 块分散在四片区的 0 级土地，按基础地价认购后从零建设。银行待售楼不收租。

每天刷新 5–8 处不期而遇，已建房产和功能设施同样可出现；先处理偶遇，再继续原地块的买地、收租或服务。十张地图各新增 15 条仅流动偶遇可见的专属事件，共 150 条；加上原有内容共 298 条。事件结果保留在后续操作窗口及本回合公开卡，通知会等待操作窗口关闭后显示。详见 [完整故事与规则](docs/ROAMING_ENCOUNTERS.md)。

## 单人测试房

在「联网好友 → 输入房间码」使用以下固定入口。进入后可选择地图和天气强度，再按「开始测试」。

|入口码|测试房|初始背包|
|---|---|---|
|`114514`|天气测试房|99 格，装满 99 件天气控制器|
|`350234`|建筑测试房|99 格，装满 99 件建筑修复包|

每位玩家拥有独立的单人测试进度，没有 AI 或其他玩家占位。默认不限季数，结束回合即进入下一天；刷新页面可用同一浏览器身份重连，主动离开后再次输入入口码会创建新测试。天气控制器仍指定明日天气，修复包仍用于自己的未抵押、未达地标层数的普通地产；受潮、天气与行动时机等正常限制继续生效。测试房同样由房间服务维护，服务器重启会清除进度，固定入口仍可重新进入。详细规则见 [单人测试房设计](docs/TEST_ROOMS.md)。

## 检查

在全新检出中运行：

```bash
npm ci
npm run build
npm test
npm audit --audit-level=moderate
```

先构建再测试，才能同时验证实际静态资源服务。CI 还检查仅安装生产依赖时的启动、HTTP/健康检查、WebSocket 和退出，以及 Docker 镜像。测试夹具在 `tests/fixtures/`，不依赖个人电脑上的临时验收文件。

## 联机接口与运行边界

浏览器通过同源 `/ws` WebSocket 接入 Node 房间服务。客户端先发送 `hello`，再发送创建、加入或重连请求；服务端广播房间快照，对回合、交易响应者和动作参数做校验。完整消息字段见 [docs/NETWORK.md](docs/NETWORK.md)。PVP 客户端不自行运行游戏引擎；电脑代理人也由服务端推进。

房间目前只保存在服务器内存中。服务器重启后，正在进行的联机房间及其进度会丢失，房间码也不能恢复；本机 JSON 存档仅支持 PVE。断线时真人座位会保留，对局暂停到该玩家重连。该项目不提供托管服务、账号系统或跨服务器房间同步；公网联机需要运行者自行部署可访问的服务。
